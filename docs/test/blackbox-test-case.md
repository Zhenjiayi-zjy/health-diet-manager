## 一、测试说明
1. 测试范围：用户模块（注册、登录）、饮食记录模块、个人信息模块
2. 测试方式：黑盒测试，不查看内部代码，仅从前端页面操作验证功能
3. 前置条件：前后端服务正常启动；浏览器可正常访问前端页面
4. 记录规则：
- 测试通过：预期结果与实际结果一致
- 测试失败：记录现象，新建Bug Issue，分配对应负责人
- 阻塞：接口异常导致无法继续后续测试

## 三、本次测试发现问题记录
1. Bug编号：BUG-01
- 问题描述：登录请求超时（超时时间超过10000ms），登录接口请求失败，无法完成登录鉴权
- 影响范围：注册、饮食记录、个人信息提交查询等需要后端接口的业务功能全部阻塞；**纯静态页面渲染不受影响，所有页面均可正常打开展示**
- 建议：后端排查接口连通性、后端服务路由，修复登录接口，修复完成后继续执行剩余用例
- 处理方式：新建Bug Issue，分配给后端负责人

## 四、测试总结
本次第一轮黑盒测试，完成全部页面静态渲染测试，所有前端页面均可正常访问渲染；在登录功能测试时发现登录接口超时Bug。页面展示层面无问题，但是涉及后端交互的业务功能被阻塞，等待后端修复接口后，继续完成注册、饮食、个人信息交互功能测试，补充测试结果到本文档。
