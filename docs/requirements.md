# 健康饮食管理系统 - 立项需求文档

## 1. 项目背景

随着大众健康意识提升，用户需要简单工具记录每日饮食、自动计算摄入热量，辅助饮食管理。本系统为轻量化饮食记录工具。

## 2. 目标用户

需要记录饮食、关注热量摄入的普通使用者。

## 3. 核心功能

1. 饮食信息录入：食物名称、食用分量
2. 热量自动计算
3. 饮食记录列表查看
4. 热量统计汇总

## 4. 用户场景

- 用户每天录入三餐食物，系统自动算出总热量
- 用户查看历史饮食记录，复盘每日摄入情况

## 5. 非功能需求

- 操作简单，页面简洁
- 数据稳定存储



## 6. 技术架构与选型

### 6.1 前端技术栈

1. 核心框架：Vue 3 + Vite 构建，采用组合式API进行页面开发
2. UI组件库：Element Plus，提供统一的表单、弹窗、导航等交互组件
3. 路由管理：Vue Router 4，实现多页面路由跳转与页面权限管控
4. 请求封装：Axios，封装统一请求/响应拦截器，对齐后端统一返回格式
5. 目录分层结构：
- views：业务页面层（登录页、首页、饮食记录页等）
- components：公共组件层（底部导航、通用表单等复用组件）
- router：路由配置层
- utils：工具函数层（请求封装、通用校验方法等）
- assets：静态资源层（全局样式、图片资源）
