# 📌 小组协作通用固定规则（全体成员遵守）
1. 禁止直接在 `dev`、`main` 分支提交修改，所有开发工作必须新建独立分支
2. 任何代码、文档变更都必须发起 PR，经过组员评审通过后方可合并
3. Commit 提交备注规范：
   - `feat`：新增功能
   - `fix`：修复 Bug
   - `opt`：功能/逻辑优化
   - `ui`：页面样式、交互调整
   - `doc`：文档、注释修改
4. PR 描述中必须填写：`Closes #任务编号`，合并后自动关联并关闭对应 Issue
5. PR 合并完成后，所有成员都需要切换到 dev 分支拉取最新代码，减少代码冲突
